CICI 2027 WEBSITE — QUICK PUBLICATION WITH GITHUB PAGES

Files:
- index.html: conference website
- CICI_2027_First_Announcement.pdf: first announcement

GitHub Pages:
1. Sign in to GitHub.
2. Create a new PUBLIC repository, for example: cici-2027
3. Upload index.html and CICI_2027_First_Announcement.pdf to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will display the public website address after deployment.

Before public use, confirm that every named committee member has agreed to be listed and that the organizer/chair information is institutionally appropriate.
